## 💡 Tips for Best Results

1. **In ChatGPT/DALL-E**: Paste the prompt directly. Add "Make it photorealistic" for realistic images.
2. **In Midjourney**: Add `--ar 1:1` for square, `--ar 9:16` for stories, `--ar 16:9` for banners.
3. **In Canva AI**: Use the "Magic Media" tool, select "Photo" style, paste prompt.
4. **In Microsoft Designer**: Paste prompt in the AI image generator box.
5. **After generating**: Add your text overlays (Spa Suite logo, taglines, pricing) using Canva or any image editor.
